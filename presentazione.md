# MasterDuel-DeckAnalyzer v1.4.2

An open-source data analytics and probability calculator tool designed for **Yu-Gi-Oh! Master Duel** players. Optimize your deck consistency, calculate opening hand probabilities (Hypergeometric Distribution), and simulate test hands locally.

## Features
- **Hypergeometric Calculator:** Determine the exact odds of drawing specific combo pieces (e.g., 1st turn starters, hand traps).
- **Meta Deck Parser:** Import decklists directly via YDK files or text format.
- **Synergy Matrix:** Evaluate structural cohesion based on current banlists and archetypes.
